## About

**KindRoots** is a farming game where you plant, grow, and harvest crops, take care of your land, and build a peaceful life one day at a time. It's built from scratch with the [Godot Engine](https://godotengine.org/) and features its own custom language.

## Features

- 🌾 Farming: till soil, plant seeds, water, and harvest crops
- 🎨 Handcrafted 2D pixel art
- 🗣️ Custom in-game language (see [KindRoots Language](#kindroots-language))

## Getting Started

### Requirements

- [Godot Engine](https://godotengine.org/download) 4.x *(adjust to the version you use)*

### Run the project

```bash
git clone https://github.com/Eduardo-Rais/KindRoots.git
cd KindRoots
```

1. Open Godot and click **Import**.
2. Select the `project.godot` file inside the cloned folder.
3. Press **F5** to play.
